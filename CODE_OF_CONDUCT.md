# Code de conduite

## Notre Engagement
Nous nous engageons, en tant que membres, contributeurs et responsables, à faire de la participation à notre communauté une expérience sans harcèlement pour tous.

## Nos Normes
Comportements encouragés : faire preuve d'empathie, respecter les points de vue différents, accepter les critiques constructives.
Comportements inacceptables : harcèlement, insultes, attaques personnelles, publication d'informations privées sans autorisation.

## Responsabilités d'Application
Les responsables de la communauté clarifient les normes et prennent des mesures appropriées et équitables face à tout comportement inacceptable.

## Portée
Ce code de conduite s'applique dans tous les espaces de la communauté, ainsi que lorsqu'une personne représente publiquement le projet.

## Application
Les comportements abusifs peuvent être signalés aux responsables du projet. Toutes les plaintes seront examinées de manière rapide et équitable.

## Directives d'Application
Les responsables appliquent ces directives : 1. Correction. 2. Avertissement. 3. Suspension temporaire. 4. Exclusion définitive.

## Attribution
Ce code de conduite est adapté du Contributor Covenant, version 2.1, disponible sur https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/
